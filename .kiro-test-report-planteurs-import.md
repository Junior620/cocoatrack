## Known Issues

### Issue 1: Import Execution Not Creating Planteurs
**Severity:** HIGH  
**Affected Tests:** Properties 12, 13, 15, 19  
**Symptoms:** Import execution returns 0 created/updated count when it should create/update planteurs

**Possible Causes:**
1. Missing or incorrect API endpoint implementation
2. Database constraint violations (e.g., unique constraint on name_norm)
3. RLS policy blocking inserts
4. Missing required fields in the insert/update query
5. Transaction rollback due to errors

**Recommended Investigation:**
- Check API endpoint logs for errors
- Verify RLS policies allow inserts for test user
- Check database constraints on planteurs table
- Verify all required fields are provided in insert query

### Issue 2: Superficie Field Mismatch
**Severity:** MEDIUM  
**Affected Tests:** Property 21 (value case)  
**Symptoms:** Superficie value not persisted to database

**Possible Causes:**
1. Field name mismatch: code uses `superficie` but DB has `superficie_hectares`
2. Type conversion issue with floating point precision
3. Field not included in insert/update query

**Recommended Fix:**
- Update code to use `superficie_hectares` field name
- Or add migration to rename field to `superficie`
- Verify field is included in all insert/update operations
